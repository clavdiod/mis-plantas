# Mis Plantas

Web app para cuidar plantas: recordatorios de riego y abono, búsqueda de cuidados por nombre con foto automática (Wikipedia), y aviso de qué plantas pierden las hojas o se secan en invierno y rebrotan en primavera.

- Las plantas se guardan en el navegador del celu (localStorage). Desde Ajustes se puede bajar y restaurar una copia.
- La búsqueda usa una base de plantas incluida (plants.js) y las fotos de Wikipedia: no necesita claves ni tiene costo.

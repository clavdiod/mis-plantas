# Mis Plantas

Web app para cuidar plantas: recordatorios de riego y abono, búsqueda de cuidados por nombre con foto automática (Wikipedia), identificación y diagnóstico por foto con Claude, y aviso de qué plantas pierden las hojas o se secan en invierno y rebrotan en primavera.

- Las plantas se guardan en el navegador del celu (localStorage). Desde Ajustes se puede bajar y restaurar una copia.
- La búsqueda y el análisis de fotos usan la API de Anthropic con una clave que se carga en Ajustes y queda solo en el celu.
